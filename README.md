# Hindsight: bug reports and ideas

This is where to report problems with **Hindsight**, the replays and build timelapses mod by Hardline Interactive,
and to suggest features. The mod's code isn't here.

- **Download:** [CurseForge](https://www.curseforge.com/minecraft/mc-mods/hindsight)
- **Guide:** [hardlineinteractive.com/mods/hindsight](https://hardlineinteractive.com/mods/hindsight/)
- **Questions and fixes for common problems:** [FAQ](https://hardlineinteractive.com/mods/hindsight/faq/)

## Reporting a bug

[Open a bug report](../../issues/new?template=bug_report.yml). The form asks for:

1. Your Minecraft version, loader (NeoForge or Fabric) and its version, and Hindsight's version.
2. What you did, what you expected, and what happened instead.
3. Your log: `logs/latest.log` from your game folder (drag the file into the box). If the game crashed, the newest
   file in `crash-reports/` too.
4. Any other mods you have installed (a modpack name is fine).

Please search the [existing issues](../../issues) first: if yours is already there, add a comment or a 👍 instead.
